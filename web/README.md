# Log Monitor - Мониторинг загрузки логов

Современный веб-интерфейс для мониторинга файлов логов в реальном времени с автоматической отправкой в ELK Stack.

## Особенности

### 🔍 Мониторинг в реальном времени
- Отслеживание изменений файлов логов
- Автоматическое обнаружение новых файлов
- Мониторинг статуса обработки

### 📊 Dashboard с аналитикой
- Статистика по обработанным файлам
- Графики производительности
- Индикаторы состояния системы

### 🔗 Интеграция с ELK Stack
- Настройка подключения к Elasticsearch
- Конфигурация Logstash pipeline
- Интеграция с Kibana dashboard

### 📁 Управление файлами
- Drag & Drop загрузка файлов
- Настройка путей мониторинга
- Фильтрация по типам файлов

### ⚙️ Гибкие настройки
- Конфигурация интервалов обновления
- Настройка уведомлений
- Управление производительностью

## Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Go (Gorilla Mux, WebSockets)
- **Интеграция**: ELK Stack (Elasticsearch, Logstash, Kibana)
- **Дизайн**: Современный responsive UI с анимациями

## Быстрый старт

### Предварительные требования
- Go 1.21+
- Git

### Установка и запуск

1. **Клонирование репозитория**
```bash
git clone <repository-url>
cd log-monitor
```

2. **Установка зависимостей**
```bash
go mod tidy
```

3. **Запуск сервера**
```bash
go run cmd/web-server/main.go
```

4. **Открытие в браузере**
```
http://localhost:8080
```

## API Endpoints

### REST API
```
GET    /api/files     - Список файлов
POST   /api/files     - Загрузка файла
POST   /api/elk/test  - Тест соединения с ELK
GET    /api/stats     - Статистика системы
```

### WebSocket
```
WS     /ws            - Реальный мониторинг
```

### Примеры событий WebSocket
```json
{
  "type": "file_updated",
  "filename": "application.log",
  "message": "Файл application.log обновлен",
  "timestamp": "2024-01-15T10:30:00Z"
}

{
  "type": "elk_sent",
  "filename": "application.log", 
  "message": "Данные отправлены в ELK",
  "timestamp": "2024-01-15T10:30:05Z"
}
```

## Конфигурация ELK Stack

### Elasticsearch
```yaml
# elasticsearch.yml
cluster.name: log-monitoring
network.host: 0.0.0.0
http.port: 9200
```

### Logstash
```ruby
# logstash.conf
input {
  beats {
    port => 5044
  }
}

filter {
  if [type] == "log" {
    grok {
      match => { "message" => "%{COMBINEDAPACHELOG}" }
    }
  }
}

output {
  elasticsearch {
    hosts => ["localhost:9200"]
    index => "logs-%{+YYYY.MM.dd}"
  }
}
```

### Kibana
```yaml
# kibana.yml
server.host: "0.0.0.0"
server.port: 5601
elasticsearch.hosts: ["http://localhost:9200"]
```

## Поддержка

### Известные проблемы
- Большие файлы могут замедлять интерфейс
- WebSocket соединения могут прерываться

### Решение проблем
1. Проверьте логи сервера
2. Убедитесь в доступности ELK Stack
3. Проверьте права доступа к файлам
